# C10B 终端 WASD 控制

这是独立的电脑端工具，所有文件都放在此文件夹，未加入 Sunward 工程，也未修改、编译或烧录小车固件。电脑通过 BLE 向现有手动控制固件发送命令。

## 怎么用

1. 关闭原来的网页/手机蓝牙连接，打开小车电源，先将使能拨到 OFF。
2. 双击本文件夹的 **启动WASD.command**，会打开终端。首次运行如出现蓝牙权限提示，允许访问。
3. 扫描约 6 秒后，输入小车蓝牙设备的编号，按回车。BT24会自动选FFE2发送、FFE1接收。如果其他模块有多个发送通道，再选择你原串口助手使用的发送特征编号。
4. 看到 **小车已回复ST=STOP，键盘控制已就绪** 后，将使能拨到 ON，等一秒。在空旷地面先短按 W，再按空格，确认能前进和停车。
5. 保持此终端窗口有键盘焦点，下面这些键都不用回车。

| 键 | 小车动作 | 发给固件的文字 |
|---|---|---|
| w（不按Shift） | 前进，目标120mm/s | 必要时先设置 `V120!`，再 `F!` |
| s（不按Shift） | 后退，目标120mm/s | 必要时先设置 `V120!`，再 `B!` |
| a（不按Shift） | 向左转弯，外侧目标120mm/s | 必要时先设置 `V120!`，再 `L!` |
| d（不按Shift） | 向右转弯，外侧目标120mm/s | 必要时先设置 `V120!`，再 `R!` |
| Shift＋W/S/A/D | 对应方向加速，目标300mm/s | 先停车确认，再 `V300!`，速度读回确认后发送方向命令 |
| 空格或 X | 停车 | `STOP!` |
| Q、Esc 或 Ctrl+C | 发停车命令并退出 | `STOP!` |

**终端不能检测松键。按下方向键后，松手仍会继续行驶；按空格停车。** 按住同一个方向键不会不断重发命令或延长行驶时间。当前固件默认每次最长10秒，转弯为向前弧线、内侧轮目标为外侧的一半；以日志V、SEC为准。到时自动停下后，先按空格，再按方向键开始下一次。

## Shift加速这样用

普通小写方向键请求120mm/s；Shift加方向键输入大写字母，请求300mm/s。比如先按w前进，再按Shift＋W加速；想降回120，松开Shift后再按一次w。左右转弯也可加速，300是外侧轮目标，内侧为150。

当前固件只允许在停车状态修改V，所以工具换速度时会先发STOP，等ST=STOP，再发V120或V300，等日志V确认后才发方向命令，途中会短暂停车。空间不足时先用空格停车。

单按或松开Shift没有可识别的终端输入，**松开Shift不会自动降速**。Caps Lock产生的大写字母也会请求300，驾驶时请关闭Caps Lock。

已核对Sunward源码的DPT_MANUAL_MAX_MMPS为300，但电脑端无法证明板上烧录的是同一版本。若板上固件不接受V300，工具会在3秒内取消切换并发STOP，提示检查速度上限，不会在未确认300时继续启动。这次只更新独立电脑工具，没有修改、编译或烧录Sunward。

程序连接时先发送一次 `STOP!`。只有收到完整DPI日志并且小车报告 `ST=STOP` 后，才允许方向键发送移动命令。这能区分收到日志与发送命令确实到达主板。蓝牙断开时电脑无法继续发送停车命令；需要立即停车时拨使能 OFF。正常退出会尝试发送停车命令，仍需看实物是否停下。

## 数据在哪里

收发内容自动保存为此文件夹 `接收记录/records-wasd-日期-时间.json`。按 Q 正常退出后，JSON 文件写入结束标记，可以直接用于后续实验分析。

## 扫不到或没有 DPI

- 本工具支持 **BLE**，不支持经典蓝牙 SPP/RFCOMM。没有扫描到模块时，先断开网页/手机连接再试；仍没有时需要确认模块型号和通信方式。
- 找到了设备却没有 DPI：检查小车是否运行带 `F!/B!/L!/R!/STOP!` 的手动固件，以及发送特征是否选对。工具不会自动烧录固件。
- 蓝牙权限被拒绝：到系统设置的隐私与安全性 → 蓝牙中，允许启动它的终端应用，然后重开工具。

## 源码和验证

`WASD.swift` 是电脑端源码；`c10b-wasd` 是已编译的 Apple Silicon Mac 程序；`Info.plist` 提供蓝牙用途说明。无需安装 Python 库。

编译和 `./c10b-wasd --self-test` 已通过。自检覆盖键位映射、重复方向过滤、停车清除待发送移动命令、Shift速度选择、停车与速度确认、取消切换和超时；没有打开蓝牙或连接实物。Shift加速的实物表现待用户验证。

技术依据：[Apple Core Bluetooth 文档](https://developer.apple.com/documentation/corebluetooth/cbperipheral)、[写入特征文档](https://developer.apple.com/documentation/corebluetooth/cbperipheral/writevalue(_:for:type:))。
