## 程序怎样计算和停车

```text
左轮距离 += TIM8有符号增量 × 周长 / 左CPR
右轮距离 += -TIM4有符号增量 × 周长 / 右CPR
里程 S = (左轮距离 + 右轮距离) / 2
剩余距离 = 200mm - S
```

只有本次启动后的增量进入该任务；不将启动前的轮子移动、上次里程或反向计数绝对值算成前进距离。16位编码器回绕按原delta16处理，左右CPR分别使用现有值。

剩余大于等于40mm时保持60mm/s基速；进入最后40mm后按剩余距离下调到最低40mm/s。低速下差速限幅随基速同比缩小，航向仍参与，两轮目标保持前进。最低基速40是本版初始试调值，用于避免目标趋零后停在终点前；真实低速表现待本轮确认。

S达到200mm后，立即制动并清两组积分，进入BRAKE。继续累计制动后编码器位移，直到两轮速度均在±5mm/s内持续200ms，才锁存DONE与最终里程。制动后最终S可能略大于200mm，用它和尺测距离一起判断停车误差。

## 日志字段和异常状态

| 字段/状态 | 含义 |
|---|---|
| M=DIST | GO20定距任务 |
| G=200 | 目标200mm |
| S / SL / SR | 本次平均/左/右里程，单位mm，整数打印 |
| T | 当前基速，接近终点由60降至40；停车时0 |
| TL / TR | 航向外环实际给两轮的目标mm/s |
| ST=BRAKE | 已制动，正在确认停稳；该状态很短，400ms日志可能没有打印到 |
| ST=DONE | 距离到达且停稳确认通过；最终S/SL/SR保留 |
| ST=TIMEOUT | 10秒内未完成距离，停车，不算成功 |
| ST=SETTLE | 制动后1.5秒仍未确认停稳，停车，不算成功 |

GO20期间DPI每400ms打印一次，HDG仍每秒一次，兼顾9600波特率蓝牙容量。V/SEC仍是手动配置，不改变GO20目标和超时。看见S=200这一条整数打印不等于达到精确触发点，程序内部用未取整的浮点里程判断。

每次重新GO20清本次里程与PI积分并保存当前朝向；重复发送不会清零里程或延长时限，BRAKE期间运动命令被忽略，不自动排队重启。STOP、实体OFF、串口接收故障以及原低压/ADC/GAP/REV/FAST/STALL/YAW保护保留。漏拍或不可信的异常计数不能触发正常完成；GO20前必须READY，启动/Reset不自动行驶。原RUN、GO三秒以及手动F/B/L/R命令仍可使用。
