## 原理：给现有轮速环一个小差速

MPU6050以Z轴测偏航、左转为正，当前量程±250°/s、灵敏度131。500次静止采样得到本次零偏，再按实际采样时间积分相对角度。

```text
航向误差 = 启动时朝向 - 当前朝向（取±180°的最短差）
差速 C = 1.0 mm/s/度 × 航向误差，限幅到±15mm/s
左轮目标 = 60 - C
右轮目标 = 60 + C
```

车头偏左：当前角度增大，误差/C为负，左轮请求更快、右轮更慢，向右修正；偏右时反过来。两轮目标范围45～75mm/s，保持前进，输出仍限1800，轮速PI仍P32/I20。

本步直接使用“轮速差/角度”的P增益，单位为mm/s/度；没有用猜测轮距换算车体角速度。后续量两驱动轮接地中心之间的轮距后，可按手册的角速度形式换算。

## 日志怎样读

DPI保留原有格式，M=HEAD表示本步；TL/TR为左右实际请求的目标，L/R为反馈轮速，UL/UR为轮速PI输出。HDG每秒打印一次，避免增加9600波特率蓝牙的持续发送负担。

| HDG字段 | 含义 |
|---|---|
| YC | NONE未校准、WARM预热、CAL采样、READY可用、FAIL校准/采样无效 |
| N | 校准样本数，READY应为500 |
| BZ100 | 本次GZ零偏×100，单位是原始计数；负号正常 |
| Y100 / E100 | 相对偏航角/航向误差×100，除100得到度 |
| C | 请求的差速mm/s，正数向左修正、负数向右修正 |
| IO_US | 最近一次MPU读取用时微秒 |

例如Y100=120表示相对左转1.20°；目标在0°时E100=-120，C约-1，左轮目标略高于右轮。GO每次重新保存当前朝向，不要求起点等于校准时的0°。

## 程序中的启动与停车边界

- 启动/Reset保持电机制动；不自动校准或运行。CAL仅在使能OFF且停车时接受，校准期间运动命令不会积压到校准结束后启动。
- 校准拒绝编码器移动、使能ON、三轴陀螺仪明显波动；恒定缓慢转动仍可能逃过波动判断，因此静止条件由操作保证。
- GO仅在已校准READY且停车时接受，重复GO不延长3秒。运行时切换到原手动命令沿用200ms制动；STOP与串口接收故障优先。
- MPU读取失败、饱和、读取超过5ms或采样间隔异常使航向失效；航向模式下停两轮。偏离目标超过20°也停止，DPI显示ST=YAW。控制漏拍仍报GAP。
- 软件I²C读取在主循环内完成，读取后再次检查实体使能再提交电机输出；原低压/ADC/反向/异常速度/堵转/串口故障停车保留。
- MPU初始化失败时GO不可用，原RUN/F/B/L/R仍可使用。蓝牙断线没有新增专用检测，GO的3秒时限和实体OFF沿用。
