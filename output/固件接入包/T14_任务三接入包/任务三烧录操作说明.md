## 按键操作

1. 重新打开Sunward工程使下载配置刷新，确认目标为Debug。电机使能OFF，烧录上面的新HEX，随后RESET。复位默认仍是任务一。
2. 将车放在A点，车头朝C斜线方向，保持OFF。长按PA0约1.5秒后松手，依次选择任务一→独立半圆→任务二→任务三；从复位起长按三次，直到OLED第一行显示 `TASK 3 AC CB BD DA`。每次长按后先松开。
3. 保持车辆静止和OFF，短按PA0并松手开始CAL，等待OLED `YC READY`。
4. 打开电机使能ON，等约0.2秒，再新短按PA0启动。路线自动执行AC→CB→BD→DA，在A停稳后声光。运行中新的按键按下或使能OFF均停车。

任务三有A启动提示和C/B/D/A四次到达提示，共5次。顶点衔接先停稳，再单轮前进转向；内侧轮目标为零并清掉本轮积分，另一轮仍执行原PI与保护。无需蓝牙参与正常任务选择、校准和启动。

初始车头必须朝C，模块会把启动时航向作为AC参考。任务三会在运行中改变方向；故障或完成后重新启动须重新回A摆车，而不是从停车点继续。

## 当前任务三参数

几何：AB=1000mm，半径400mm，AC/BD≈1280.6mm，α≈38.66°，弧段1256mm。斜线和巡线巡航200mm/s、起步50mm/s、转向60mm/s、捕获50mm/s，总超时40秒。保留原巡线增益64、差速上限80mm/s、左右PI与编码器参数。任务三独立参数在 `Core/Inc/car_config.h` 的 `DPT_TASK3_*`；窗口、转向/捕获距离仍是初版值。

C处左转对正右侧半圆，CB沿右侧半圆向上；B处左转对正BD；D处右转对正左侧半圆，DA回A。LF04纠偏反馈的左右/极性保持原来设置。

40秒包含加减速、顶点停稳、对正和捕获、最终停稳；超过则TIMEOUT停车。当前主机测试不能证明实物40秒达标、车身投影覆盖每个顶点或沿弧保持覆盖。两个方向的弧长、传感器偏置与转向位移仍需真实场地验证。

## OLED故障记录

第一行TASK3，第三行例如 `LOST CB T13.4s`，第四行例如 `P8 F7 S800 Y90`。停车时保留这些字段，可直接记录第三、四行来定位，不依赖实时串口。

| P状态 | 含义 |
| --- | --- |
| 0 | IDLE |
| 1 | 斜线AC或BD |
| 2 | 顶点停稳 |
| 3 | 转向对正 |
| 4 | 捕获入弧线 |
| 5 | 巡线半圆 |
| 6 | A最终停稳 |
| 7 | 完成 |
| 8 | 锁存故障 |

| F故障 | 含义 |
| --- | --- |
| 0 | 无 |
| 1 | 配置无效 |
| 2 | OFF/STOP或整车保护取消；具体原因看第三行 |
| 3 | 传感器/节拍/数值错误 |
| 4 | 40秒超时 |
| 5 | 直线/捕获航向超差 |
| 6 | 预期入口/出口缺失或捕获越界 |
| 7 | 半圆丢线 |
| 8 | 对正超时或位移过大 |
| 9 | 停稳超时 |
| 10 | 里程反向/异常 |

S是当前路线段的平均编码器里程，Y是当前相对航向角。P2/P3/P4衔接时S暂时包含顶点相关移动；进入新斜线/半圆后重新建立段基线。
