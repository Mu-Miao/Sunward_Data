# 9.4.2下一步：静止零偏、手转角度、30秒漂移

你已实测：偏航Z轴、左转正、右转负；这次静止GZ约-423。现在新增每次启动的静止零偏校准，再观察相对转角。不会把-423永久写成固定零偏，也不控制电机。

左右按站在车尾、面向车头定义。只适用于刚才已通过通信和量程读回的Sunward工程；MPU6050陀螺仪设置仍是±250°/s，131 raw/(°/s)。CubeMX设置不用再改变。

## 3. main.c启动诊断

## 4. 替换主循环，避免在100ms if里面采样

找到main.c中的`/* Infinite loop */`，把从这一行到main函数结尾（SystemClock_Config函数定义前）的循环段完整换成：

```c
  /* Infinite loop */
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    YawDiag_Poll();
  }
  /* USER CODE END 3 */
}
```

最后一个`}`是main函数的结束，保留SystemClock_Config及其后所有代码。旧100ms if在这轮不用；原始打印函数可保留，但不再调用。

**为什么：** Poll必须由主循环反复调用。它内部安排采样和日志，不再由外层100ms if把采样限制到每秒10次。不需要加HAL_Delay；按实际时间间隔做积分，不连续“补跑”读取同一个新数据来冒充漏掉的采样。

## 5. 编译、烧录：先做静止校准

两个LAB_TEST_CMD继续为0，Lab_MotorTestOnce调用继续注释。小车在平整桌面上放好，再按Reset。

启动后会依次看到：

```text
YAW WARMUP 2s; keep car still until CAL OK
YAW CAL: keep still, 500 samples (about 5s)
YAW CAL OK BIAS_Z=... SPAN_Z=...; YAW=0.00 AGE_MS=0
YAW=... W=... GZ=... DT_US=... AGE_MS=...
```

从Reset开始到CAL OK前保持完全静止，通常需要约8秒（含MPU初始化）。不要在CAL OK前转车。BIAS_Z是这次校准结果，可能接近-423，也可能因温度、时间而变化；省略号只是格式示意，不是预设值。

校准时记录500组GZ均值作为bias，同时检查三轴最大最小差。明显晃动会报CAL UNSTABLE；此时重新放稳并按Reset。检查阈值只是实验用的明显运动筛查，不能证明“绝对静止”；匀速慢转也可能通过，因此必须由你保证车不动。

若提示READ FAIL、CLOCK FAIL、GAP >30ms或SATURATED，不继续把后续角度当有效结果。先处理问题再Reset；程序不会自行补出丢失的角度。

## 6. 先看校准后的静止结果

| 输出字段 | 意思 |
|---|---|
| BIAS_Z | 本次静止平均GZ，单位raw |
| SPAN_Z | 校准期间GZ最大值减最小值，单位raw |
| YAW | 从CAL OK之后零点开始累加的相对角度，单位度 |
| W | 扣除零偏后的Z轴角速度，单位度/秒 |
| GZ | 当前原始值；静止时仍可约为-423，不必变成0 |
| DT_US | 最近一次读取与上一次读取的实际间隔，单位微秒 |
| AGE_MS | 自角度置零后的经过时间，单位毫秒 |

CAL OK后继续静止约3秒，W应在0附近波动，YAW应在0附近小幅变化。不要要求每一行完全为0，也不要加“把小角速度强行清零”的死区来掩盖漂移。

内部计算为：

```text
W = (GZ - 本次BIAS_Z) / 131
YAW += (上一次W + 本次W) / 2 × 实际dt
```

这是相对角度，不是绝对罗盘方向。换量程后不能继续使用131；本文件没有自动改量程的逻辑。

## 7. 手动左转约90°

在纸上画两条互相垂直的线，或使用方格纸，把初始车头方向与第一条线对齐。重新放好车、Reset，保持静止直到CAL OK，再开始测试。

1. 保持车身水平，让车头向左转到第二条垂直方向；用约2～3秒完成，尽量平顺。
2. 可以不匀速，但避免突然甩动、倾斜或被USB线拉扯。
3. 停住后看YAW，应为正，量级接近+90°；等约1秒记录值。
4. 向右转回初始方向，YAW应接近0，记录回到原位后的值。

记录：真实方向、参考转角、停止时YAW、回到原位的YAW。手摆的90°有对齐误差，因此第一轮先确认符号和量级，再评估误差；没有量角参考不能宣称角度精度已标定。

若转得过快超过±250°/s量程，数据会饱和，程序提示SATURATED并停止。本轮不用电机带着车转。

## 8. 另做一次右转约90°

重新对齐初始方向、Reset，等CAL OK再右转约90°。停止时YAW应接近-90°；左转回原位时接近0。

不用把第一轮的当前位置强行当作新的0，Reset会重新校准并置零；等待阶段不能移动。

## 9. 另做一次静止30秒漂移

把车放稳、Reset，等CAL OK后完全不碰车。到AGE_MS约30000时记录YAW，并导出串口日志。

```text
本次BIAS_Z：________ raw
起始YAW：0.00°
AGE_MS约30000时YAW：________ °
30秒漂移：结束YAW减起始YAW = ________ °
```

左右90°测试和静止30秒测试分开做。不能把转过90°之后的角度误当成“从0开始的静止漂移”，也不能只看W某一行接近0就认定30秒角度无漂移。
