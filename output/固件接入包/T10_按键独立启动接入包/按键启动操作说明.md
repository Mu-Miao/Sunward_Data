## 操作顺序

1. 实体使能开关保持 **OFF**，烧录本版HEX，上电或复位时松开KEY_U。
2. 车放稳，OFF状态短按并松开KEY_U。LED1开始慢闪，表示校准预热和采样；保持车静止约7～8秒，直到LED1常亮。常亮表示陀螺仪已校准（YC=READY）。
3. 把车对准前进方向，切到 **ON**，等约1秒，再短按并松开KEY_U。开始执行现有1米直行任务，运行时LED1熄灭。
4. 到目标后制动、确认停稳，LED1和LED2加蜂鸣器提示一次500ms；之后LED2和蜂鸣器关闭，LED1恢复常亮。
5. 运行中再短按KEY_U会停车；实体OFF和原STOP!也可以停车。一次按键仅触发一次，要稳定松开后才能再次触发。

ON本身不会启动；重新上电需重新校准。ON时未READY按键只记录WAIT，不会等待校准完成后自动行驶。OFF状态按键会重新校准；校准期间再次按键会取消校准（YC=NONE），要松开后在OFF重新按一次。若切到ON仍在校准，校准失败，不能启动。

## 灯与日志

| 情况 | LED1 | LED2 / 蜂鸣器 |
|---|---|---|
| 未校准，停车 | 熄灭 | 关闭 |
| WARM / CAL | 每250ms切换亮灭，完整周期500ms | 关闭 |
| READY且停车 | 常亮 | 关闭 |
| RUN / BRAKE | 熄灭 | 关闭 |
| 校准或陀螺仪FAIL，停车 | 每100ms切换亮灭，完整周期200ms | 关闭 |
| GO100正常完成提示 | 与LED2一起亮500ms，随后恢复READY常亮 | 亮 / 响一次500ms，随后关闭 |

LED1常亮只说明陀螺仪READY；低压、ADC故障等原保护仍可能拒绝启动。LED2和蜂鸣器仍只在GO100停稳完成时提示；提前按键停车不会鸣响完成提示。未校准或校准失败时保持OFF、放稳后重新按KEY_U。

原USB/蓝牙文本指令CAL!/GO!/GO20!/GO100!/RUN!/F!/B!/L!/R!/STOP!和V/TIME继续保留。新增短日志例如：

```text
KEY EN=0 RAW=1 ARM=0 EVT=1 ACT=CAL TASK=1
HDG YC=READY N=500 ...
KEY EN=1 RAW=1 ARM=0 EVT=2 ACT=START TASK=1
KEY EN=1 RAW=1 ARM=0 EVT=3 ACT=STOP TASK=1
```

EN=0/1分别表示实际使能OFF/ON；RAW是PA0原始电平，ARM表示是否已经稳定松开、允许新的按下事件；EVT是消抖后的有效按下次数；ACT是最近一次按键处理结果，BLOCK代表被条件或同批STOP/接收故障拦截。KEY日志约每秒一次，按键事件后提前报告，日志队列满不阻塞停车。TASK=1为当前固定的一米任务，没有新增任务2～4的选择或路线。
