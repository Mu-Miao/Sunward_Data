# 右轮PI：保持P=32、I=20，观察8秒

2026-10-08 14:31的日志已经显示积分逐步增大，速度靠近60mm/s，且结束和停车时积分归零。3秒末尾仍有速度变化，先增加观察时间，避免同时改增益和时长。本轮只在固定架空、上一轮没有明显抖动且停车正常时运行。

## 修改三处

main.c和CubeMX不用改。你可以在Sunward的正确位置直接修改下列三处；本包另提供修改后的同名文件，若采用覆盖，只覆盖Core/Inc和Core/Src中的文件，不在Core这一层新增副本。

1. `/Users/mzh/STM32Cube/Sunward/Core/Inc/right_p_test.h`：

```c
#define RPT_DURATION_MS     8000U
```

目标60、Kp32、Ki20、上限1800保持不变。

2. `/Users/mzh/STM32Cube/Sunward/Core/Src/right_p_test.c`的`RightPTest_Begin()`里，将：

```c
RPT_DURATION_MS == 0U || RPT_DURATION_MS > 3000U) return HAL_ERROR;
```

改为：

```c
RPT_DURATION_MS == 0U || RPT_DURATION_MS > 8000U) return HAL_ERROR;
```

这是初始化允许的最长测试时间。只改头文件、未改这处检查，会出现RPI init FAIL。

3. 同一`.c`文件的启动提示改成：

```c
static const char banner[] = "RPI: send RUN! or STOP!; right A only; 8s; PI active\r\n";
```

## 操作

1. 固定车身、双轮架空。打开电池主电源，使能先OFF。
2. 编译下载，连接115200/8N1串口后Reset。启动提示应是8s，停车等待时U=0、I=0，BAT应在此前电池接通时约1350附近，而不是仅USB时约474。
3. 使能ON，等1秒，ASCII单次发送RUN!，观察到8秒自动停止。不要循环发送。
4. 停3秒，再发送一次RUN!，再等自动停止。保持左右轮映射及机械条件与上一轮相同，不增加人为负载。
5. 如果明显抖动、持续超出目标或反复启停，立即STOP!并拨OFF，结束重复测试。
6. 导出日志给我，说明有无抖动、以及两次是否都在8秒自动停下。重点检查后半段V是否维持在目标附近、I是否不再持续大幅增加、结束后U/I是否归零。

保留原ADC门槛、1800输出限幅、故障停车和积分复位。8秒是这轮台架观察时间，不是允许落地运行的说明，也不保证MCU停死后的自动停车。遇到软件无响应，用电池主电源开关切断电机供电。
