# 9.5第一步：手转轮子，验证轮速测量

这一步只测速度，不调用电机驱动，也不启动PI。CubeMX不用增加配置。

使用16:28复测平均值：左轮TIM8每圈60104.33，右轮TIM4每圈59996.33；暂按两轮直径均65mm，计算轮周长0.2042035m。这些是初步换算参数：须确认每段均为按标记完整一圈、两轮直径相同。若有不同，先修改头文件常量。不是厂商标称参数，也没有宣称长期精度。

## 1. 复制两个文件

- 本接入包`Core/Inc/wheel_speed_diag.h`复制到`/Users/mzh/STM32Cube/Sunward/Core/Inc/`。
- 本接入包`Core/Src/wheel_speed_diag.c`复制到`/Users/mzh/STM32Cube/Sunward/Core/Src/`。

编译时确认新`.c`参与编译；不要只复制头文件。保留电机测试A/B命令均为0，`Lab_MotorTestOnce()`仍注释。

## 2. main.c中的三个改动

在`USER CODE BEGIN Includes`中增加：

```c
#include "wheel_speed_diag.h"
```

在`USER CODE BEGIN 2`末尾，将原来的：

```c
if (lab_mpu_ready) {
    YawDiag_Begin(&huart1);
}
```

替换为：

```c
if (WheelSpeedDiag_Begin(&huart1, &htim8, &htim4) != HAL_OK) {
    Lab_Write("SPD init FAIL\r\n");
    Error_Handler();
}
```

保留前面已经启动的TIM4/TIM8编码器、TIM2中断、制动初始化，以及MPU初始化读回代码。速度测量不依赖MPU初始化是否成功，先独立验证编码器。

在`while (1)`里面的`USER CODE BEGIN 3`，删掉当前100ms的`if (...)`编码器打印块，改成仅一行：

```c
WheelSpeedDiag_Poll(lab_tick10_count);
```

原先`YawDiag_Poll()`保持注释。不要删掉包围`while`和`main`的花括号。只保留这一种循环诊断，避免叠加UART打印影响读取时机。

`HAL_TIM_PeriodElapsedCallback()`维持原样：TIM2中断里只递增`lab_tick10_count`，不要放串口打印。

## 3. 为什么这样接

TIM2每10ms发布一次节拍，主循环发现新节拍后读取编码器。使用DWT实际经过的时间换算，而不是把100ms打印当作10ms采样；若一次积压多个节拍，不重复使用同一计数假装补采样，记录MISS。

每约500ms只输出一行，用这个窗口累计的净计数和实际时长算平均轮速。打印很慢时也可能扰动采样，因此同时观察DT和MISS；此实现是诊断代码，不代表已经验收了正式实时控制任务。未来PI应使用每拍轮速，不直接把此500ms平均值当作每10ms的新反馈。

左轮使用`d8`，右轮使用`-d4`，使左右前进都显示正速度。轮速公式：

```text
轮速(m/s) = 正向编码器增量 / 每圈计数 × 轮周长(m) / 实际间隔(s)
```

输出使用整数mm/s，避免当前工程未启用浮点printf时打印空白。1mm/s=0.001m/s；显示0可能包括不足半mm/s的微小平均速度。

## 4. 实物怎么测

1. 编译、下载，连接串口115200/8N1后按Reset。看到`SPD DIAG`和持续的`SPD`行。
2. 架空并固定车身，双轮完全静止约5秒。
3. 单独把左轮按前进方向慢转，再快转，停下；随后反转。右轮保持不动。
4. 右轮同样操作，左轮保持不动。每种状态维持约2～3秒，停顿也留2～3秒，避免平均窗口跨状态导致误读。
5. 导出完整日志，告诉我哪段对应慢转、快转、反转。

例子（格式示例，不是你的实测结果）：

```text
SPD L=0 R=0 mm/s N=50 DT=9995..10005 us MISS=0
SPD L=45 R=0 mm/s N=50 DT=9995..10005 us MISS=0
SPD L=-30 R=0 mm/s N=50 DT=9995..10005 us MISS=0
```

看这些现象：静止时左右接近0；前进正、反转负；快转的速度幅值比慢转大；只转一轮时另一轮接近0。N约50、DT接近10000µs、MISS通常为0；如果有持续漏拍或明显长间隔，先处理测量调度，再接PI。串口数值只证明读取、方向及换算逻辑，真实m/s精度还需用滚动距离/时间校核。

完成后再加入左右两套PI、输出限幅和停车条件。当前不需要猜Kp、Ki，也不需要让车落地自动跑。
