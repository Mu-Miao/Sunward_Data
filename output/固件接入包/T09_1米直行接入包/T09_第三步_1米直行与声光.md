## 新命令的速度与停车

| 项目 | GO20保留 | GO100新增 |
|---|---:|---:|
| 编码器目标里程 | 200mm | 1000mm |
| 基速 | 60mm/s | 起步40mm/s，渐增至120mm/s |
| 起步目标增速率 | 原行为 | 100mm/s²，约0.8s到120 |
| 减速区间 | 最后40mm | 最后100mm |
| 末段基速下限 | 40mm/s | 40mm/s |
| 驱动阶段超时 | 10s | 13.5s |
| 制动后停稳确认 | 两轮均±5mm/s内持续200ms | 相同 |
| 制动阶段超时 | 1.5s | 相同 |
| 完成提示 | 原行为 | DONE后声光一次500ms |

120mm/s是本版初始目标，尚未验证实际地面速度。原60mm/s理论走1米就需16.7秒，无法满足手册15秒要求，因而为GO100单独设置巡航速度；不调整此前PI增益、轮周长或1800输出上限。1米速度基准更高，最后100mm提前减速。航向差速仍最多±15mm/s，低速时同比收窄；不因120基速把差速限幅自动翻倍。

本版超时限制为驱动13.5秒加制动1.5秒，不代表已经验证15秒内成功。未到目标触发TIMEOUT，制动未停稳触发SETTLE，两者都没有完成提示。低压、ADC、UART、GAP、REV、FAST、STALL、YAW、STOP与OFF停车保留。完成后的500ms声光另计；到点停稳后记录DONE才是运动完成时刻。

目标1000mm是开发阶段的车体参考点里程；正式A→B摆放与覆盖B还要按手册选择同一车体参考点，不凭前置探头到点来判定覆盖。

## 完成声光与日志

PC2/PC3低电平点亮两盏灯，PA15高电平鸣响；已核对现有GPIO初始化与JTAG释放。提示在BRAKE确认停稳进入DONE时启动，主循环计时500ms关闭，不调用HAL_Delay，不阻塞STOP或控制任务。长时间停在DONE不会反复提示；STOP、OFF、新运动或重新CAL会取消仍在进行的提示。

```text
DPI ... ST=RUN   M=DIST ... S=... SL=... SR=... G=1000 SIG=0
DPI ... ST=BRAKE M=DIST ... S=... SL=... SR=... G=1000 SIG=0
DPI ... ST=DONE  M=DIST ... S=... SL=... SR=... G=1000 SIG=1
DPI ... ST=DONE  M=DIST ... S=... SL=... SR=... G=1000 SIG=0
```

S/SL/SR/G单位mm；M=DIST共用于两种定距命令，以G=200或1000区分。SIG=1是软件声光输出活动标志，不证明实物灯和蜂鸣器确实工作。DPI约400ms一帧，HDG约1秒一帧；满发送队列可能丢日志，但不等待日志发完才停车。最终S包含制动后的编码器增量，可能略大于1000mm；实际距离仍待未来尺测。
