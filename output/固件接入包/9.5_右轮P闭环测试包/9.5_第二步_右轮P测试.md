# 9.5第二步：架空右轮，手动启动一次3秒P闭环测试

先固定架空车身，两轮都离地。代码只驱动右轮A前进，左轮B制动。Reset不会自动启动；串口明确发送`RUN!`才启动一次测试。不要启用串口循环发送。初始只调P，Ki=0，尚不是完整PI或落地行驶程序。

初始试调参数：目标60mm/s，Kp=24 PWM计数/(mm/s)，最大命令1800，时长3秒。这组Kp是起始试调值，不是已调好的参数。对应使用m/s作为单位的旧LabPI时Kp=24000；不能把24直接抄到旧m/s函数。按此前A在1200能启动的现象，速度为0时本组P输出1440，再根据实际反馈增减。

换算暂按右轮一圈59996.33、直径65mm；须确认此前每段是标记整圈、两轮外径同为65mm。若不同，修正CPR和周长再测。

## 3. 实物操作

1. 固定车身、两轮架空。使能开关先OFF，打开电池主电源，连接串口115200/8N1，编译下载后按Reset。
2. 等持续出现RPI日志。此时`T=0 U=0 ST=IDLE`，轮子应不转。若BAT低于1200，先核对电池主电源，不能用USB单独供电跑此测试。
3. 将使能开关拨ON，等待至少1秒。串口发送框输入`RUN!`，选择ASCII，HEX关闭，只发送一次。
4. 观察右轮是否朝前转、左轮是否停住。程序最多运行3秒，随后`ST=DONE T=0 U=0`并制动。不要手抓正在转动的轮子。
5. 再发送一次`RUN!`；右轮开始后约1秒发送`STOP!`，应显示`ST=STOP U=0`并停止。
6. 再发送一次`RUN!`；开始后拨使能OFF，应显示`ST=OFF U=0`并停止。保持OFF再发送RUN!，不应启动。
7. 导出日志给我，注明第一次是否转起来、方向是否正确，STOP和OFF能否停止。

示例格式（不是实测结果）：

```text
RPI T=60 V=38 U=528 BAT=1350 DT=10000 ST=RUN
RPI T=0 V=0 U=0 BAT=1350 DT=10000 ST=DONE
```

T、V单位mm/s；V是打印时最近一次约10ms采样的速度，不再是上一步500ms平均值。U是A电机原始正命令，B始终0。BAT是ADC原始值，DT单位µs。

## 4. 异常时照表操作

| ST | 意思与操作 |
|---|---|
| OFF | 使能不满足；确认PC13 ON=0，不修改代码绕过 |
| LOW | BAT低于1200；核对电池电源和电压，不降低门槛硬跑 |
| ADC | ADC失败或读数过期；检查ADC读取，不启动电机 |
| GAP | 漏节拍或采样间隔异常，已制动；导出日志，先不提高Kp |
| REV | 运行中持续测到反向速度，已制动；核对编码器符号和轮子方向 |
| FAST | 速度超过本次测试范围，已制动；保持OFF并导出日志 |
| STALL | 有至少1200的命令却约半秒几乎不动，已制动；检查轮子是否被挡、供电、使能和驱动，不持续重复启动 |
| UART | 串口收发失败，已制动并退出诊断；同一串口可能无法打印该状态 |

第一轮先保持Kp=24、Ki=0、目标60和上限1800不变，把日志给我。P控制可能长期低于目标，或者低速时启停，这本来就是本轮要观察的现象，不直接加I掩盖问题。

BAT门槛1200按3.3V参考、11倍分压估算约10.64V，是本次短时台架测试的门槛，不是已确认的电池化学体系截止电压。3秒、使能和故障停车是软件逻辑；若MCU停死，软件不能保证撤掉输出，需要电池主电源开关停止。当前只做固定架空台架测试，不作为落地行驶固件。
