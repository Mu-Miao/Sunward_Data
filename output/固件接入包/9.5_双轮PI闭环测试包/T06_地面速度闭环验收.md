# T06：地面速度闭环验收

对应手册9.5、逐日计划第一天T06。基础闭环已调通，当前补地面负载、不同速度目标与停车实测。2026-10-09用户补充：之前15.6cm短跑是在桌面带载测试，首次无抖动、3秒后停下，复验仍约15.6cm、无明显偏向。现在改用有缝隙的瓷砖地板，先用RUN!的60mm/s、3秒在相同路径复测两次，记录是否跨缝；地面基线正常后继续不同目标响应和地面STOP/OFF。通过后进入T09航向与定距直行。

## 先做两次60mm/s、3秒短跑

沿用当前固件保留的`RUN!`：左右目标60mm/s，P32/I20，每轮输出上限1800，3秒自动结束。无需修改或重新烧录固件。

1. 使能OFF，连接已经用通的串口或蓝牙文本助手，关闭循环发送，确认持续收到DPI。使用USB时让线松弛，不能拉扯车身；蓝牙测试无需USB跟车。
2. 电池供电，把车放在平整空地，前方至少留50cm；用尺子记录同一车体参考点的起始位置和朝向。
3. 使能ON，等1秒，单次发送`RUN!`。确认日志为`M=TEST TL=60 TR=60`，观察向前运行、抖动、偏向和3秒自动停。
4. 停稳后OFF，测量同一参考点的前进距离、横向偏移。第一轮正常才摆回起点重复第二轮，保留两轮日志。
5. 若堵转、剧烈抖动、持续偏转到场地外，或出现LOW/ADC/GAP/REV/FAST/STALL/UART故障，立即OFF并保存记录，先分析这轮，不继续提高目标。

现有WASD工具没有`RUN!`键：小写`w`请求120mm/s手动前进，大写`W`/Shift+W请求300mm/s。此次用能发送文本命令的助手；不要拿W键代替本轮60mm/s基线。只开一个蓝牙连接。

60mm/s恒速3秒的计算距离为18cm，起步过程会让实际距离缩短，因此不把18cm设为通过门槛。轮速日志按初始CPR和65mm直径换算，地面打滑或滚动周长误差仍需用实测距离核对。

## 基线正常后，补不同目标的响应

保持地面、摆放、电池与PI参数一致，通过文本助手做两组从静止起步的3秒测试。每条命令分别发送、等待日志确认，不拼成一串。

| 测试 | 停车后的配置与启动 | 运行日志检查 |
|---|---|---|
| 低目标 | `STOP!` → 确认ST=STOP → `V60!` → 确认V=60 → `TIME3!` → 确认SEC=3 → `F!` | M=FWD，TL/TR=60 |
| 高目标 | 上轮停稳、摆回起点；`STOP!` → 确认ST=STOP → `V120!` → 确认V=120 → 确认SEC=3 → `F!` | M=FWD，TL/TR=120 |

两组手动测试的每轮输出上限都为3000，便于在相同上限下比较目标提高后的响应。保留的RUN实验上限为1800，不把它和120mm/s手动运行的差异全部归于目标变化。这里是两次0→目标的起步响应，未实现运行中60→120连续阶跃；当前固件不接受运行中的V配置。

高目标只在低目标正常后执行，前方至少留1m。两轮均检查3秒自动停。另用一次低目标短跑分别补STOP与实体OFF停车观察，每项停稳后再开始下一项；OFF测试不能同时发STOP，否则无法区分停车原因。配置拒绝、目标不符或无持续日志时不启动。

## 通过后进入自动直行

下一项T09先做短距离航向保持，再接编码器里程、终点减速与停车。数据流为：MPU相对航向 → 航向P控制 → 左右轮目标 → 已验收速度PI；编码器同时累计距离。

当前Sunward主循环调用DualPITest_Poll，YawDiag_Poll仍注释；MPU初始化不等于已接入纠偏。接入前核对运行用的静止零偏、航向符号、左右有效滚动周长及轮距。相对里程从每次启动重新计数；停车清积分，保留STOP/OFF与现有故障保护。

先用短距离验证偏航修正方向、里程与停稳误差，随后做A→B、端点声光提示和重复验收。LF04黑白标定暂缓不妨碍白地直行开发，圆弧任务仍须补齐标定。只有T09实车路线通过才记录项目1完成。
