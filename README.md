## 归档说明

本仓库初次上传于 2026-10-14。根据项目用途筛选上传内容；本地历史文件保留原样。

不上传：旧版车架和重复项目压缩包、完整固件备份、历史接入包中重复的完整工程、临时报告与渲染中间文件、编译产物和缓存、厂家软件安装包、个人编辑器状态及原始调试接收日志。具体规则见 [.gitignore](.gitignore)。保留最新 T29 的交付 HEX 与 V19 打印 ZIP，便于按对应说明使用。

部分历史文档和脚本包含原机器的绝对路径，或引用仅保存在本地的历史模型。原 [项目导航](项目导航.md) 与 [Obsidian 首页](车车项目首页.md) 为本地入口；在 GitHub 浏览时优先使用本页的相对链接。T29 完整工程已包含 `Core`、`Drivers`、启动文件、链接脚本、工程配置和测试源码。

软件验证、固件烧录和实车测试分别记录；当前测试结果以实测记录为准。
